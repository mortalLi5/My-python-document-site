# 常见问题

## Python 和 Python3 有什么区别？

在 macOS 和 Linux 上，`python` 有时指向 Python 2，而 `python3` 指向 Python 3。建议统一使用 `python3`。

## 怎么安装第三方库？

使用 pip：

```bash
pip install 库名
```

例如安装 requests：

```bash
pip install requests
```

## 运行 Python 文件报语法错误怎么办？

!!! tip "排查步骤"
    1. 检查是否有中文标点符号，比如中文括号、引号。
    2. 检查缩进是否一致，不要混用空格和 Tab。
    3. 检查 Python 版本，有些语法需要 Python 3.6 以上。
